Tentang saya

Halo, saya Karlita Agustin, mahasiswa D3 Teknologi Informasi di Politeknik Negeri Madiun. Saya tertarik pada pengembangan teknologi yang bermanfaat dalam kehidupan sehari-hari, terutama analisis dan desain sistem memahami kebutuhan pengguna, lalu menuangkannya menjadi rancangan yang jelas sebelum dibangun. Selama kuliah, saya belajar membuat aplikasi web, aplikasi mobile, dan perangkat IoT, merancang tampilan dengan Figma, serta mengelola kode lewat Git dan GitHub.

Saya pernah menjalani magang industri selama 6 bulan di PT Cyber Olympus Indonesia (CROG Robotic International), Yogyakarta, pada divisi Teaching Internship Staff. Di sana saya mengembangkan aplikasi Android dengan Kotlin untuk memantau tanaman pakcoy pada sistem Smart Hydroponic, mulai dari merancang antarmuka, menghubungkan data sensor lewat Firebase Realtime Database, hingga membuat fitur penjadwalan pompa.

Portofolio

SmartHydroponic

Aplikasi Android untuk memantau kondisi tanaman pakcoy pada sistem hidroponik pintar. Menampilkan data pH, TDS, dan UV secara real-time dari sensor, grafik ringkasan, kontrol pompa nutrisi, serta jadwal pompa otomatis. Saya mengerjakan sisi aplikasi, mulai dari desain antarmuka hingga integrasi Firebase.

Teknologi

  • Kotlin
  • Android Studio
  • Firebase Realtime Database
  • Figma
  • ESP32

ADF Petro

Rancang bangun sistem informasi manajemen operasional Pom Mini ADF PETRO berbasis web, dikerjakan dalam tim. Mencakup analisis kebutuhan perangkat lunak untuk peran Superadmin, Administrator, dan Karyawan Operator Shift, jadwal proyek, serta rancangan basis data.

Teknologi

  • Analisis & Desain Sistem
  • MySQL
  • Git & GitHub

Pemesanan Bucket

Sistem informasi pemesanan bucket yang membantu pencatatan pesanan dan pengelolaan data secara terkomputerisasi, sebagai pengganti pencatatan manual. Saya mengerjakan analisis kebutuhan, perancangan, dan pengembangannya.

Teknologi

  • PHP & Laravel
  • MySQL
  • HTML & CSS

Quislish
